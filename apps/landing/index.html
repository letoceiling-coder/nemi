Частые вопросы

Какие системы поддерживаются?

Сейчас — Windows 10/11 (x64). Версия для macOS и мобильное приложение-компаньон для iPhone и Android запланированы после стабилизации Windows-версии.

Нужно ли что-то устанавливать отдельно?

Нет. Установщик содержит всё необходимое. Модели работают через подключённые серверы — локальная установка Ollama не требуется.

Куда уходят мои данные?

История и настройки хранятся локально, файлы — в вашем приватном хранилище. Для ответов используются модели на сервере; для чувствительных документов будет режим «только свой сервер».

Может ли ассистент отправить письмо без меня?

Только если вы сами включите такое правило. По умолчанию каждая отправка требует подтверждения.
