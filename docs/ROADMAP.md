## PHASE 2 — AGENT SYSTEM 🟡
Orchestrator · LangGraph · главный агент · специализированные агенты · Tool Registry · Plugin SDK · разрешения · очереди · обработка ошибок.
Результат: ассистент выполняет многоэтапные поручения.

Сделано 2026-11-13 (v0.2.0): главный агент (цикл «модель ↔ инструменты», до 6 шагов, на вашем сервере, резерв — OpenRouter), Tool Registry с уровнями риска (`read` / `write` / `confirm`) и пометкой «уходит в интернет», подтверждение «Разрешить / Отклонить» в чате, аварийная остановка, обработка ошибок инструментов, защита `web_fetch` от обращений к локальной сети. Инструменты: дата/время, память (поиск, запись, удаление с подтверждением), прошлые диалоги, веб-поиск, чтение страниц, открытие во встроенном браузере. Шаги агента сохраняются в истории.
Не сделано: специализированные агенты, Plugin SDK, очереди фоновых задач, LangGraph (пока не нужен: цикл свой, простой и проверяемый).

## PHASE 3 — PERSONAL MANAGEMENT 🟡
Проекты · задачи · календарь · напоминания · память · отчёты · автоматизации.

Сделано 2026-11-13 (v0.3.0): задачи и проекты в базе (сроки с временем и без, приоритет, статус, заметки, источник «ассистент»), быстрый ввод по-русски без модели, напоминания уведомлением Windows (опрос раз в 30 с, каждое доставляется один раз), инструменты агента `tasks_list / task_create / task_update / task_delete (подтверждение) / projects_list`, разделы «Задачи» и «Проекты», правая панель и счётчик на реальных данных. Память — с фазы 1.
Сделано 2026-11-13 (v0.4.0): календарь — события (время/весь день, место или ссылка, проект, напоминание за N минут), пересечения, быстрый ввод с длительностью, инструменты агента `day_overview / calendar_list / event_create / event_update / event_delete (подтверждение)`.
Не сделано: синхронизация с Google/Яндекс Календарём, повторяющиеся события и задачи, отчёты, автоматизации (в интерфейсе пока примеры).
