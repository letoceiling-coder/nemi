## PHASE 1 — CORE PLATFORM 🟡 (в работе)
Результат: работающая основа приложения.

| Пункт ТЗ | Статус | Что есть / что осталось |
|---|---|---|
| Git-репозиторий | 🟡 | Инициализирован, первого коммита ещё нет |
| Архитектура | ✅ | Tauri 2 + React 19 + FastAPI, `docs/architecture/` |
| Windows-приложение | 🟡 | Tauri-оболочка, трей, автозапуск backend. Нет установщика `.exe` (нужно упаковать backend в sidecar) |
| Дизайн интерфейса | ✅ | Прототип всех разделов, тёмная/светлая тема |
| Backend | ✅ | FastAPI, авторизация, аудит, изоляция пользователей |
| Подключение моделей (вместо Ollama) | ✅ | Свой сервер `api.siteaccess.ru` → запасной OpenRouter |
| Model Manager | 🟡 | Список моделей, роли (Вариант B), выбор в чате. Нет: лимит расходов, флажок «только свой сервер» в UI |
| Базовый AI-чат | ✅ | Потоковый чат, файлы, markdown, история диалогов из БД («Недавние»: открыть, удалить) |
| Локальная база | ✅ | SQLite (WAL) |
| Базовая память | ✅ | Факты о пользователе из чата (без секретов), поиск bge-m3, раздел «Настройки → Память», отметка «Запомнил» в чате |
| Подключение S3 | ✅ | Приватный бакет Selectel, SHA-256 |
| Логи | ✅ | Журнал аудита + файл `logs/api.log` с ротацией (2 МБ × 5) и маскировкой ключей, токенов, паролей, поисковых запросов; «Настройки → Диагностика» показывает реальное состояние и журнал |
| Системный трей | 🟡 | Работает. Не проверено: выход из трея гасит backend |
